## 🧩 LLM Knowledge Quiz — Can You Beat an AI Engineer?

> 🎮 Click the option you think is correct! (It's markdown — open the spoilers to check answers)

**Q1: What does "RAG" stand for in AI?**

<details><summary>A) Recurrent Attention Graph</summary>❌ Nope! That's not it.</details>
<details><summary>B) Retrieval-Augmented Generation ✅</summary>✅ Correct! RAG combines retrieval from a vector DB with LLM generation to reduce hallucinations.</details>
<details><summary>C) Random Agent Graph</summary>❌ Good try, but no.</details>

**Q2: What is MCP (Model Context Protocol) used for?**

<details><summary>A) Training models faster</summary>❌ Not quite!</details>
<details><summary>B) A standard protocol exposing tools/data to LLMs from external servers ✅</summary>✅ Exactly! MCP lets LLMs call external APIs, databases, and services in a standardized way — I build these!</details>
<details><summary>C) Compressing model weights</summary>❌ Nope.</details>

**Q3: What is LoRA used for?**

<details><summary>A) Real-time voice streaming</summary>❌ Wrong track!</details>
<details><summary>B) Efficient fine-tuning of large models by training low-rank adapter layers ✅</summary>✅ Yes! LoRA (Low-Rank Adaptation) lets you fine-tune LLMs cheaply — I used it with FinBERT on 86K+ financial articles.</details>
<details><summary>C) Vector similarity search</summary>❌ That's what ChromaDB/QDrant do.</details>
