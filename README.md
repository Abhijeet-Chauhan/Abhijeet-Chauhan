I build production AI systems. Not prototypes — things that run when markets open, pick up real phone calls, and process live financial data across two countries simultaneously. The gap between an AI demo and an AI product is infrastructure, observability, and not cutting corners. That's what I focus on.

**Brainfog Agency · AI/ML Engineer** &nbsp;`Aug 2025 – present` &nbsp;· Mumbai 🇮🇳

---

<br/>

**IRIS** &nbsp; `live` &nbsp; `UAE (DFM / ADX) + India (NSE / BSE)`

Six specialised LangGraph agents — Technical, Sentiment, Fundamental, Broad Market, Ranking, ReAct — running in parallel over live market data. Ships React UI components mid-stream via a GenUI layer so the UI updates as inference runs. MCP server exposes every financial tool as a callable API. Sentiment agent powered by FinBERT fine-tuned on 86,000+ domain articles.

&nbsp;&nbsp;&nbsp;&nbsp;`LangGraph` `MCP` `FastAPI` `Redis` `React` `PostgreSQL` `Docker` &nbsp;·&nbsp; **Docker: 14 GB → 2.5 GB**

<br/>

**Maven** &nbsp; `live` &nbsp; `voice AI`

Production voice assistant end-to-end: WebRTC ingestion → Google Live API → Groq Whisper STT → VAD → silence detection → streaming LLM response → Twilio outbound call. Every layer optimised for latency. Sub-second from speech to reply.

&nbsp;&nbsp;&nbsp;&nbsp;`WebRTC` `Twilio` `Groq Whisper` `Google Live API` `VAD` &nbsp;·&nbsp; **< 1 s end-to-end**

<br/>

**Nexa** &nbsp; `microservices` &nbsp; `voice platform`

Voice AI rebuilt as independent fault-tolerant services: RAG, multi-agent orchestration, voice processing, API gateway. LiveKit streaming. WebRTC-to-PSTN telephony bridge over SIP/WebSocket — connects to standard telephone infrastructure without a vendor lock.

&nbsp;&nbsp;&nbsp;&nbsp;`LiveKit` `RAG` `SIP/WebSocket` `Microservices` `Groq Whisper`

<br/>

**ContentFlow** &nbsp; `automation`

End-to-end AI content pipeline: schedules and publishes across LinkedIn + X, parses social signals into CRM-ready lead profiles via an LLM intelligence layer, runs background generation jobs on Supabase Postgres Cron without manual intervention.

&nbsp;&nbsp;&nbsp;&nbsp;`Gemini API` `Supabase` `Async Workers` `LLM Pipelines`
